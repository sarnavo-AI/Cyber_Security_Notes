[_Whois_](https://www.domaintools.com/support/what-is-whois-information-and-why-is-it-valuable/) is a protocol that uses TCP port 43 to communicate with public databases. The whois tool queries the databases to retrieve domain registration records.

A forward search means querying WHOIS with a domain name to discover who owns it.

Reverse WHOIS queries are especially useful when we begin with an IP address but want to learn more about the entity behind it.

Forward lookup
```
whois megacorpone.com -h 192.168.50.251
```

Reverse lookup
```
whois 38.100.193.70 -h 192.168.50.251
```

-h means the querying whois server for the information
