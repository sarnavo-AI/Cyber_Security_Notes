The `robots.txt` file instructs web crawlers, such as Google's search engine crawler, to allow or disallow specific resources.
## Operators:

1) site:                                                       for specific domain
2) filetype:                                                 for specific files
3) ext:                                                        for php, js, css, extensions
4) -filetype:html                                        for returning result except html pages
5) intitle:"index of" "parent directory"      for pages that contain "index of" in the title and the words "parent directory" on the page
