On Windows 11, [_Network Level Authentication_](https://en.wikipedia.org/wiki/Network_Level_Authentication) (NLA) is enabled by default for RDP connections. Because _OFFICE_ is not a domain-joined machine, _rdesktop_ won't connect to it. We can use _xfreerdp_ instead, which supports NLA for non-domain-joined machines.

A sub procedure is very similar to a function in VBA. The difference lies in the fact that sub procedures cannot be used in expressions because they do not return any values, whereas functions do.
